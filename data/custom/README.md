# 自定义评测数据集

此目录用于存放用户自定义的评测数据集。

## 数据格式

请确保您的自定义数据集遵循 `ms-swift` 标准格式。基本格式如下：

### 单轮问答格式

```json
{
  "query": "这是一个问题",
  "response": "这是标准回答"
}
```

### 多轮问答格式

```json
{
  "history": [
    {"role": "user", "content": "第一轮问题"},
    {"role": "assistant", "content": "第一轮回答"}
  ],
  "query": "当前问题",
  "response": "标准回答"
}
```

### 包含多模态数据

对于包含图像、音频等多模态数据的数据集，请在目录中包含相应的媒体文件，并在 JSON 中通过相对路径引用：

```json
{
  "query": "分析这张图片中的内容",
  "image": "images/sample.jpg",
  "response": "标准分析结果"
}
```

## 使用方法

1. 将您的数据集文件（.jsonl 格式）放在此目录或其子目录中
2. 在 WebUI 或命令行中指定数据集文件路径
3. 如果数据集包含媒体文件（图像、音频等），请确保它们在引用路径下可访问

## 注意事项

- 建议使用 `.jsonl` 格式（每行一个 JSON 对象）
- 请勿将敏感或隐私数据放在此目录中
- 大型数据集建议放在 `data/custom/local_data/` 目录中，该目录已在 `.gitignore` 中被排除
